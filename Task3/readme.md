## Переход с REST на Kafka
1. Ещё одна точка репликации, при сбое других сервисов работа будет продолжаться пока есть события
2. RPS на сервисы снижается, не требуется каждый раз опрашивать о новых данных, они автоматически приходят сразу как получают другие сервисы. Скорость обработки данных увеличивается.
3. При росте внешних сервисов для скачивания их тарифов нагрузка на сервис минимальная, при их сбое другие интеграции не будут затронуты
4. Так же работа через kafka снижает связность сервисов между собой.
5. Создание новых страховых заказов является критичной функциональностью, поэтому передача данных идет через outbox паттерн. Это поможет не потерять сообщений при передаче в kafka.
